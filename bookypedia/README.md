# Bookypedia-2

Решение второй версии Bookypedia.

Добавлены:
- таблица `book_tags`;
- атомарные операции изменения данных;
- ввод/создание автора при `AddBook`;
- нормализация тегов;
- `DeleteAuthor`, `EditAuthor`;
- расширенный `ShowBooks`;
- `ShowBook`, `DeleteBook`, `EditBook`.

Строка подключения читается из `BOOKYPEDIA_DB_URL`.
