# Bookypedia

Консольное приложение для ведения книжного каталога. В нём можно добавлять, просматривать и изменять информацию о книгах и авторах, а также связывать книги с тегами. Данные сохраняются в PostgreSQL, поэтому не пропадают после завершения работы программы.

**Технологии:** C++20, PostgreSQL, libpqxx 7.7.4, CMake.
